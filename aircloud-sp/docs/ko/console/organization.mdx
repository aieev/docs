조직(Organization)은 팀 또는 회사 단위의 최상위 관리 단위입니다. 멤버, 프로젝트, 사용량, 결제가 모두 조직 단위로 통합 관리됩니다.

<Card title="AirCloud 조직 운영 권장 사항" type="tip">
  - 프로젝트 목적에 따라 **API 테스트용 Project와 운영용 Project를 분리**하세요.
  - 안정적인 조직 운영을 위해 **멤버별 역할과 접근 범위를 정리**하는 것이 좋습니다.
  - 서비스의 지속적인 운영을 위해 **과금과 사용량을 정기적으로 확인**하세요.
  - 배포 전 **크레딧 및 결제 상태를 확인**하세요.
</Card>

## 멤버 초대

Organization에 멤버를 초대하고 역할을 지정할 수 있습니다. 역할에 따라 설정 관리 권한이 구분됩니다.

![Organization Members 페이지](/images/image-10.png)

| 역할 | 설명 |
| :-- | :-- |
| **소유자 (Owner)** | 조직의 모든 설정을 관리할 수 있습니다. 멤버 초대 및 역할 변경, 결제 및 크레딧 관리, <br />프로젝트 생성·삭제를 포함한 전체 권한을 가집니다. |
| **멤버 (Member)** | 지정된 프로젝트에 접근해 서비스를 이용할 수 있지만, <br />조직 설정을 변경하거나 결제 기능에 접근할 수 없습니다. |

조직 관리 페이지의 **멤버** 탭에서 오른쪽 상단 **\+ 초대** 버튼을 클릭해 멤버 초대 창을 엽니다.

1. **이메일 입력**: 초대할 멤버의 이메일 주소를 입력합니다. 쉼표(,)로 여러 명을 한 번에 초대할 수 있습니다.
2. **역할 선택**: **소유자** 또는 **멤버** 중 부여할 역할을 선택합니다.
3. **프로젝트 접근 권한 설정**: 해당 멤버가 접근할 수 있는 프로젝트를 선택합니다. **전체 선택**으로 모든 프로젝트에 접근을 허용하거나, 개별 프로젝트를 체크박스로 지정할 수 있습니다.
4. **초대**: **초대** 버튼을 클릭하면 입력한 이메일 주소로 초대 메일이 발송됩니다.

![팀원 초대 화면](/docs/images/quickstart/quickstart-invite-team.png)

<Card title="멤버 초대 시 유의사항" type="warning">
  - **AirCloud는 1계정 1조직 원칙을 적용합니다.** 초대받는 멤버가 이미 다른 조직에 소속된 경우 초대가 불가합니다.
  - 초대 메일을 받은 주소와 동일한 이메일로 회원가입해야 합니다.
  - 기존 계정으로 로그인된 상태에서 초대 수락을 누르면 오류가 발생할 수 있으므로, 동일한 디바이스에서 작업할 경우 먼저 로그아웃한 뒤 진행하는 것이 좋습니다.
</Card>

## 사용량 관리

#### 사용량

![Image](/images/image-21.png)

사용량 페이지에서는 조직의 기간별 지출을 시각적으로 확인할 수 있습니다. 컨테이너와 API 사용량을 10분 간격으로 측정하며, 실제 크레딧 차감액은 **정산 내역** 탭에서 확인할 수 있습니다.

**조회 옵션**

상단 **조회 옵션**을 펼치면 아래 항목을 설정할 수 있습니다.

| 항목 | 설명 |
| :-- | :-- |
| **조회 기간** | 시작일과 종료일을 직접 지정하거나, **오늘 / 7일 / 1개월 / 3개월 / 6개월 / 1년 / 전체 기간** 중 빠르게 선택합니다 |
| **조회 단위** | 차트와 테이블을 **일별** 또는 **월별**로 집계합니다 |
| **서비스** | **전체 / Air Container / Air API** 중 조회할 서비스를 선택합니다 |
| **미사용 항목** | 사용량이 없는 항목까지 결과에 **포함**할지, **제외**할지 선택합니다 |

**요약 카드**

| 카드 | 설명 |
| :-- | :-- |
| **TOTAL SPEND** | 조회 기간 전체 사용 비용 합계 |
| **ON DEMAND** | On-demand GPU 사용 비용 |
| **RESERVED** | 장기 임대 자원 사용 비용 |
| **API CALL** | Air API 호출 비용 |

**사용량 트렌드**

차트는 예약(RESERVED) 비용을 제외한 Air Container·Air API 사용 비용만 집계해 보여줍니다. 하단 테이블에서는 조회 기간 내 조직별 사용량을 일자(또는 월) 단위로 확인할 수 있습니다.

#### 정산 내역

![Image](/images/image-22.png)

정산 내역은 조직에서 실제로 **차감·충전된 크레딧 기록**입니다. 사용량 페이지가 10분 단위로 측정된 사용량을 보여준다면, 정산 내역은 그 사용량이 실제로 크레딧에 반영된 결과를 보여줍니다.

**조회 옵션**

| 항목 | 설명 |
| :-- | :-- |
| **조회 기간** | 시작일과 종료일을 직접 지정하거나 빠른 기간 선택(오늘/7일/1개월/3개월/6개월/1년/전체 기간)을 사용합니다 |
| **조회 단위** | **조직 / 프로젝트 / 컨테이너** 중 조회 기준을 선택합니다. 프로젝트 또는 컨테이너를 선택하면 하위 항목을 태그로 선택해 필터링할 수 있습니다 |
| **미사용 항목** | 사용량이 없는 항목까지 결과에 **포함**할지, **제외**할지 선택합니다 |
| **사용 유형** | 조회 단위에 따라 선택 가능한 옵션이 달라집니다. <br /><br />\* **조직**: Reserved / On Demand / API Call<br />\* **프로젝트**: On Demand / API Call<br />\* **컨테이너**: On Demand |
| **거래 유형** | **전체 / 입금 / 출금** 중 선택합니다 |

<Tip>
  어떤 컨테이너에서 비용이 얼마나 발생했는지 확인하려면 조회 단위를 **컨테이너**로 변경하세요. 삭제된 컨테이너의 내역도 조회할 수 있어 과거 지출 분석에 유용합니다.
</Tip>

**집계 보기 / 건별 보기**

우측 상단 토글로 두 가지 방식으로 정산 내역을 확인할 수 있습니다.

| 보기 | 설명 |
| :-- | :-- |
| **집계 보기** | RESERVED / ON DEMAND / API CALL 유형별로 묶어서 표시합니다. 각 그룹은 접고 펼칠 수 있으며, 합계 행을 포함합니다 |
| **건별 보기** | 10분 간격으로 발생한 개별 거래를 한 줄씩 표시합니다. 각 행을 펼쳐 상세 내역을 확인할 수 있습니다 |

**집계 보기 테이블 컬럼**

| 그룹 | 컬럼 |
| :-- | :-- |
| **RESERVED** | 결제일, GPU 모델, 수량, 적용 기간, 결제 금액, 상태 |
| **ON DEMAND** | 조직, GPU 종류, 사용 시간, 청구 금액 |
| **API CALL** | 조직, 모델, 호출 수, 토큰, 청구 금액 |

**건별 보기 테이블 컬럼**

| 컬럼 | 설명 |
| :-- | :-- |
| **결제 날짜** | 해당 거래가 크레딧에서 차감·충전된 시각 |
| **타입** | 거래 유형 (입금 / 출금) |
| **사용 유형** | 워크로드 과금 방식 (On Demand, Reserved, API Call 등) |
| **구간** | 과금 대상 시간 구간 (예: `2026-07-22 11:20:00 ~ 2026-07-22 11:30:00`) |
| **크레딧** | 해당 구간에서 차감·충전된 크레딧 |

행 왼쪽의 화살표를 클릭하면 아래 상세 내역이 펼쳐집니다.

![Image](/images/image-23.png)

| 상세 항목 | 설명 |
| :-- | :-- |
| **GPU** | 사용된 GPU 모델 |
| **사용 구간** | 과금이 발생한 10분 구간 |
| **시간당 단가** | 해당 GPU의 시간당 요금 |
| **작업 유형** | 워크로드 종류 (예: `SERVE_REPLICA`) |
| **차감 금액** | 해당 구간에서 차감된 크레딧 |
| **원본 설명** | 과금 시스템이 기록한 원본 설명 |

**정산 내역 내보내기**

우측 상단 **내보내기** 버튼을 클릭하면 조회한 정산 내역을 파일로 다운로드할 수 있습니다.

- **기간**: 내보낼 정산 내역의 날짜 범위를 지정합니다
- **컬럼**: 내보낼 항목을 선택하고 드래그로 순서를 변경할 수 있습니다
- **형식**: CSV / JSON / TXT 중 선택합니다

<Info>
  거래 건수가 많은 경우 내보내기 처리에 수 분이 소요될 수 있습니다.
</Info>

## 장기 임대

**장기 임대**는 자주 쓰는 GPU를 **1개월 이상** 장기로 확보해 두는 기능입니다. 임대 기간에는 같은 GPU로 컨테이너를 돌려도 임대한 수량만큼은 사용 요금이 붙지 않고, 기간이 길수록 시간당 요금이 할인됩니다.

임대는 조직 단위라 산하 프로젝트가 함께 쓰며, **조직 → 장기 임대**에서 관리합니다.

<Card title="장기 임대" icon="calendar-clock" href="/docs/ko/console/long-term-rentals" arrow="true">
  기간과 할인, 결제, 상태, 취소·환불, 컨테이너에 적용되는 조건을 확인하세요.
</Card>

## 조직 설정

조직 설정 페이지에서는 조직의 기본 정보를 확인하고, 결제 방식과 결제 수단을 관리할 수 있습니다. 조직 소유자(Owner)만 접근할 수 있으며, 변경 사항은 **저장** 버튼을 클릭해야 최종 반영됩니다.

| 항목 | 설명 |
| :-- | :-- |
| **조직 이름** | 조직을 식별하는 이름 |
| **조직 설명** | 조직의 용도나 팀을 설명하는 짧은 텍스트 |
| **결제 방식** | **선불** 또는 **후불** |
| **결제 수단** | 크레딧/인보이스 결제를 위해 등록한 카드 |
| **조직 ID** | 조직을 식별하는 고유한 값. 조직 ID는 조직 생성 시 자동 발급되며 변경이 불가합니다. |

AirCloud는 크레딧 충전 후 서비스를 이용하는 선불 방식이 기본이며, 일부 기업 고객에 한해 후불 결제를 지원합니다. 후불 결제를 희망하는 기업 또는 단체는 지원팀으로 [문의](https://www.aieev.com/ko/contact)해 주시기 바랍니다.

| 결제 유형 | 설명 |
| :-- | :-- |
| **선불** | 크레딧을 먼저 충전한 후 사용량만큼 차감하는 방식 |
| **후불** | 서비스를 먼저 이용한 후 정산 주기에 맞춰 인보이스로 청구하는 방식 |

후불 결제의 경우, 보유한 크레딧을 우선 차감하며 잔액이 0 미만으로 떨어지면 사용량이 마이너스로 누적됩니다. 매월 말일에 누적된 마이너스 잔액만큼 인보이스가 자동 발행되고, 결제가 완료되면 잔액이 0으로 복구됩니다. **자동 결제** 옵션을 활성화하면 발행된 인보이스에 대해 결제가 자동 진행되기 때문에 결제 수단 등록을 권장합니다.
