**장기 임대**는 자주 쓰는 GPU를 1개월 이상 장기로 확보해 두는 기능입니다. 임대 기간에는 같은 GPU로 컨테이너를 돌려도 임대한 수량만큼은 사용 요금이 따로 붙지 않습니다. 기간이 길수록 시간당 요금이 할인돼 오래 쓸수록 총 비용이 줄어듭니다.

임대는 **조직 단위**라 산하 프로젝트 어디서나 함께 쓸 수 있습니다.

**조직 → 장기 임대**에서 확인하고 관리할 수 있습니다.

<Card title="임대와 컨테이너의 관계" type="info">
  임대는 요금을 미리 내 두는 것이지, 컨테이너를 대신 띄워 주는 기능이 아닙니다. 컨테이너는 평소처럼 직접 만들고 시작해야 합니다. 실행 중인 컨테이너가 진행 중인 임대와 맞으면 임대한 수량까지는 추가 비용 없이 돌아가고, 그 수량을 넘는 만큼은 온디맨드로 청구됩니다.
</Card>

## 핵심 조건

| 항목 | 내용 |
| :-- | :-- |
| **최소 기간** | 1개월 |
| **기간 프리셋** | 1개월, 2개월, 3개월, 6개월, 1년, 또는 직접 지정 |
| **할인** | 기간이 길수록 시간당 요금이 낮아집니다. 할인이 가장 큰 기간에는 **추천** 표시가 붙습니다. |
| **결제** | 임대가 확정되면 전체 기간 금액이 크레딧에서 한 번에 차감됩니다. |
| **적용 범위** | 조직 전체 — 산하 모든 프로젝트가 공유합니다. |
| **시간대** | 임대 시각은 모두 KST(한국 표준시) 기준입니다. |

## 임대 신청하기

콘솔에서 바로 임대하는 기능은 자원 준비가 끝나는 대로 열릴 예정입니다. 그전까지는 같은 화면의 **임대 문의**를 이용해 주세요.

1. **조직 → 장기 임대**에서 임대를 시작합니다.
2. **GPU**, **수량**, **기간**을 선택합니다.
3. 영구 볼륨을 **켠** 컨테이너용인지 **끈** 컨테이너용인지 선택합니다.
4. 시간당 단가, 적용 할인, 총액을 확인하고 제출합니다.

문의를 접수하면 담당자가 자원 확보 가능 여부를 확인해 **영업일 1일 이내**에 연락드립니다. 이 단계에서는 결제가 발생하지 않으며, **요청됨** 상태인 동안에는 언제든 요청을 철회할 수 있습니다.

<Warning>
  임대의 영구 볼륨 설정은 실제 배포 구성과 같아야 합니다. 영구 볼륨을 쓰는 컨테이너는 전용 노드 풀에서 돌기 때문에, 볼륨을 끈 구성으로 임대해 두면 적용되지 않고 사용한 만큼 또 청구됩니다.
</Warning>

### 즉시 확정되지 않고 요청으로 접수되는 경우

콘솔에서 바로 임대하더라도 아래 상황에서는 즉시 확정되지 않고 요청으로 접수됩니다.

| 상황 | 처리 방식 |
| :-- | :-- |
| 해당 기간에 여유 자원이 부족함 | 일부 수량만 즉시 확정할 수 있습니다. 수량을 줄여 바로 임대하거나, 나머지를 요청으로 남길 수 있습니다. |
| 가용 수량을 확인할 수 없음 | 확인 없이 확정하면 장비를 못 받을 수 있어, 담당자가 먼저 확인합니다. |
| 크레딧 부족 (후불 조직) | 인보이스로 처리합니다. |

선불 조직은 결제 단계에서 크레딧이 모자라면 같은 창에서 바로 충전하고 임대를 마칠 수 있습니다.

## 상태

| 상태 | 설명 |
| :-- | :-- |
| **요청됨** | 문의가 접수되어 담당자가 확인 중입니다. |
| **임대 예정** | 임대가 확정되었고 아직 시작 전입니다. |
| **임대 중** | 임대가 진행 중이며 조건이 맞는 컨테이너에 적용됩니다. |
| **만료됨** | 임대 기간이 끝났습니다. |
| **취소됨** | 임대가 취소되었습니다. |

목록에서는 임대별로 GPU, 수량, 기간, 시간당 단가, 결제 금액, 남은 일수를 확인할 수 있습니다.

## 취소와 환불

- **임대 시작 전** — 언제든 취소할 수 있으며 전액 크레딧으로 환불됩니다.
- **임대 시작 후** — 직접 취소할 수 없습니다. [문의 및 피드백](/docs/ko/support/contact-and-feedback) 페이지로 문의해 주세요.
