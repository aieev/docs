크레딧 충전 및 결제 관련 기능은 **조직 > 결제(Billing)** 메뉴에서 사용할 수 있습니다.

## 과금 구조

프로젝트에서 발생하는 모든 사용량과 과금은 조직 단위로 통합 관리 및 정산되며, 조직이 보유한 크레딧 한도 내에서 서비스를 이용할 수 있습니다.

크레딧 단위는 **C**로 표기하며, 원화 조직은 **1 C = 공급가 1원**입니다. 달러 조직은 같은 잔액을 당일 환율로 환산한 금액으로 표시합니다. AirCloud의 모든 서비스는 충전한 크레딧에서 차감됩니다.

![크레딧 충전 화면](/docs/images/purchase-au.png)

<Card title="참고 사항" type="info">
  - 크레딧은 API 호출, GPU 사용, 스토리지 등 AirCloud의 모든 서비스에 쓰입니다.
  - 크레딧 충전 시에는 관련 법령에 따라 부가가치세(VAT) 10%가 별도로 부과됩니다.
  - 한 번에 충전할 수 있는 금액은 **10,000 C ~ 10,000,000 C**입니다.
  - 크레딧이 모두 소진될 경우 이메일로 고지되며, 미충전 상태가 지속될 시 워크로드가 강제 종료됩니다.
  - 워크로드가 강제 종료되지 않도록 자동 충전 기능을 설정해두는 것이 좋습니다.
</Card>

![크레딧 및 결제 화면](/docs/images/billing-and-credits.png)

## 크레딧 충전

AirCloud는 아래 결제 서비스를 통해 크레딧을 충전할 수 있습니다.

- **Toss Payments**: 한국, 선불 충전
- **PayPal**: 글로벌, 선불 충전
- **Stripe**: 글로벌, 선불 충전 및 자동 충전용 카드 저장

## 카드 등록 및 관리

자동 충전 기능을 이용하려면 결제 카드를 등록해야 합니다. 등록된 카드는 자동 충전뿐만 아니라, 이후 크레딧을 충전할 때 별도의 카드 정보 입력 없이 바로 결제할 수 있습니다. 여러 개의 결제 카드를 등록할 수 있으며, 자동 충전 활성화 시 사용할 카드를 지정해야 합니다.

![Image](/images/image-14.png)

## 자동 충전

잔여 크레딧이 일정 수준 이하로 감소했을 때 크레딧을 자동으로 충전하는 기능입니다. 미리 등록한 결제 카드로 자동 결제가 진행되므로, 별도의 충전 작업 없이 크레딧을 유지할 수 있습니다.

<Frame>
  ![Image](/images/image-13.png)
</Frame>

자동 충전을 사용하려면 다음 항목을 설정해야 합니다.

- **기준 금액**: 자동 충전이 실행될 잔여 크레딧 기준
- **충전 금액**: 자동으로 충전할 크레딧 수량
- **결제 카드**: 자동 결제에 사용할 등록된 카드

## 이메일 알림

잔여 크레딧이 사용자가 설정한 기준 이하로 감소했을 때 조직 소유자(Owner)에게 이메일을 발송하는 기능입니다. 크레딧을 자동으로 충전하지는 않으며, 사용자가 직접 충전할 수 있도록 현재 크레딧 상태를 안내합니다.

![Image](/images/image-7.png)

- **기준 금액**: 이메일 알림을 발송할 잔여 크레딧 기준
- **이메일 수신 대상**: 조직 소유자(Organization Owner)

<Info>
  크레딧 부족 알림은 이메일만 발송하며 크레딧이 자동으로 충전되지는 않습니다.
</Info>

## 인보이스

인보이스는 후불 결제 방식으로, 기업 고객을 위한 결제 기능입니다. 매월 말일을 기준으로 사용량이 정산되며, 정산 시점의 누적 미결제 사용 금액을 기준으로 자동 발행됩니다.

발행된 인보이스는 **조직 > 결제 > 인보이스 목록**에서 확인할 수 있으며, 결제 상태 조회, 인보이스 다운로드, 결제 진행이 가능합니다.

| 컬럼 | 설명 |
| :-- | :-- |
| **청구 기간** | 인보이스가 발행된 청구 기간 |
| **상태** | 현재 인보이스의 결제 상태 |
| **크레딧 합계** | 해당 인보이스에 포함된 총 크레딧 사용량 |
| **청구 금액** | 결제해야 하는 금액 |
| **결제 기한** | 인보이스의 결제 마감일 |
| **결제** | 미결제 인보이스에 대한 결제 진행 |
| **다운로드** | 인보이스 파일(PDF) 다운로드 |

| 상태 | 설명 |
| :-- | :-- |
| **결제 대기** | 인보이스가 발행되었으며 아직 결제가 완료되지 않은 상태 |
| **결제 완료** | 인보이스 결제가 정상적으로 완료된 상태 |
| **연체** | 결제 기한이 경과하여 미납 상태인 인보이스 |
| **취소됨** | 인보이스가 취소되어 더 이상 결제가 필요하지 않은 상태 |

## 결제 내역

조직에서 발생한 모든 결제 및 크레딧 지급 이력을 확인할 수 있습니다.

| 컬럼 | 설명 |
| :-- | :-- |
| **날짜** | 결제가 발생한 일시 |
| **ID** | 결제 고유 ID |
| **타입** | 결제 유형 |
| **상태** | 결제 처리 상태 |
| **가격** | 실제 결제 금액 |
| **크레딧** | 지급 또는 충전된 크레딧 |
| **영수증** | 영수증 다운로드(지원되는 결제 건) |

처리 결과에 따라 <kbd>대기 중</kbd> / <kbd>완료</kbd> / <kbd>실패</kbd> / <kbd>취소됨</kbd> 상태로 구분되며, 완료된 건의 영수증을 다운로드할 수 있습니다.

| 결제 유형 | 설명 |
| :-- | :-- |
| **크레딧 결제** | 크레딧을 구매한 내역 |
| **프로모션 코드** | 프로모션 코드를 통해 지급된 크레딧 |
| **자동 충전** | 자동 충전으로 채워진 크레딧 |
| **인보이스 결제** | 인보이스를 통해 결제한 내역 |

결제 내역은 **타입**, **상태**, **기간**으로 필터링하고 **날짜순, 가격순, 크레딧순**으로 정렬할 수 있습니다.

## 프로모션 코드 등록

이벤트, 파트너십, 체험 프로그램 등을 통해 제공되는 프로모션 코드는 **결제(Billing) > 프로모션 코드 입력** 메뉴에서 등록하여 사용할 수 있습니다.

![Image](/images/image-9.png)

프로모션 코드가 정상적으로 등록되면 크레딧이 자동 충전되고, **결제 내역(Payment History)**에서 <kbd>프로모션 코드</kbd> 유형으로 지급 내역을 확인할 수 있습니다.

## 결제 취소와 환불

카드로 결제한 크레딧 충전은 **지급된 크레딧을 한 번도 사용하지 않았다면** 콘솔에서 직접 취소할 수 있습니다. 취소하면 결제 금액이 **부가세를 포함한 전액** 원래 결제 수단으로 환불되고, 지급된 크레딧(보너스 포함)은 즉시 회수됩니다. 아래 조건을 만족하는 결제라면 결제 후 경과한 기간에 제한은 없습니다.

취소할 수 있는 결제는 다음 조건을 모두 만족해야 합니다.

- 결제 상태가 **완료**이고, 결제 유형이 **크레딧 결제** 또는 **자동 충전**입니다.
- 카드 또는 PayPal로 결제했습니다. 등록된 카드로 자동 결제되는 자동 충전 건도 포함됩니다.
- **결제한 본인**이 취소합니다. 다른 멤버가 결제한 건은 그 멤버만 취소할 수 있습니다.
- 그 결제로 지급된 크레딧을 **전혀 사용하지 않았습니다.** 일부라도 사용했다면 취소할 수 없습니다.
- 결제 시점에 잔액이 마이너스가 아니었습니다. 잔액이 마이너스일 때 충전하면 지급액 일부가 미납분 상계에 쓰이므로, 새 크레딧을 쓰지 않았더라도 취소할 수 없습니다.

<Warning>
다음 항목은 콘솔에서 취소할 수 없습니다.

- 지급된 크레딧을 일부라도 사용한 결제
- 잔액이 마이너스인 상태에서 결제해 일부가 미납분 상계에 쓰인 결제
- 프로모션 코드, 가입 크레딧, 설문 리워드 등 무상으로 지급된 크레딧 — 결제 내역이 없어 현금으로 환불되지 않으며, 유효기간이 있는 크레딧은 만료일이 지나면 자동으로 소멸합니다.
- 인보이스 결제
- 정기 결제로 충전된 크레딧 — 오프라인 계약·인보이스로 수납해 콘솔에 결제 건이 남지 않습니다. 취소·환불은 담당자에게 문의해 주세요.
- 장기 임대 — 이 절차로는 취소되지 않습니다. 임대 시작 전이라면 [장기 임대](/docs/ko/console/long-term-rentals) 화면에서 직접 취소할 수 있고, 취소·환불 조건도 그 문서에 있습니다.
- 크레딧 지급 내역이 남아 있지 않은 오래된 결제 — 취소 대상이 아니라고 표시되면 [문의](/docs/ko/support/contact-and-feedback)를 남겨 주세요.
</Warning>

### 결제 취소 방법

1. **결제 → 결제 내역** 탭에서 **결제 취소** 버튼을 누릅니다.
2. 취소할 결제를 선택합니다. 취소할 수 없는 결제는 흐리게 표시되고, 마우스를 올리면 사유를 확인할 수 있습니다.
3. 취소 사유를 선택하고 취소 금액을 확인한 뒤 **확인**을 누릅니다.

취소가 처리되면 결제 상태가 <kbd>취소됨</kbd>으로 바뀌고 크레딧 잔액이 그만큼 줄어듭니다. 카드사 환불이 명세서에 반영되는 시점은 카드사에 따라 다릅니다.

### 청구 이의와 세금

청구서에 이의가 있는 경우 **청구서 수령일로부터 15일 이내**에 이의를 제기해야 하며, 해당 기간 내 이의가 없으면 청구 금액이 승인된 것으로 간주됩니다.

서비스 이용 요금은 세금 별도 금액이며, 회사의 법인세를 제외한 모든 세금, 관세 및 공과금은 고객이 부담합니다.

자세한 약관은 [서비스 이용 약관](https://www.aieev.com/ko/termsofservices)을 참고하거나 [문의 및 피드백](/docs/ko/support/contact-and-feedback) 페이지를 통해 문의해 주세요.
