필요한 GPU·템플릿·모델이 없을 때, 별도로 문의를 넣지 않고 콘솔에서 바로 요청할 수 있습니다. 모든 요청은 **요청 내역**에 모이며, 여기서 진행 상태와 담당자 답변을 확인할 수 있습니다.

## 요청할 수 있는 것

| 요청 | 시작하는 곳 | 내용 |
| :-- | :-- | :-- |
| **대기 신청** | 컨테이너 생성 화면의 GPU 선택 | 품절된 GPU에 대해 신청합니다. 재고가 확보되면 콘솔 알림과 이메일로 알려 드립니다. |
| **레플리카 한도 증가** | 레플리카 설정, 또는 한도 화면 | 조직이 실행할 수 있는 레플리카 수를 늘립니다. 승인되면 새 한도가 자동으로 적용됩니다. |
| **GPU 요청** | GPU 선택 | H200, B200처럼 아직 제공하지 않는 GPU 모델을 요청합니다. |
| **템플릿 요청** | 템플릿 선택 | 템플릿 목록에 없는 프레임워크나 이미지를 요청합니다. |
| **모델 요청** | Air API 모델 목록 | Air API에서 쓰고 싶은 모델을 요청합니다. |
| **임대 문의** | 장기 임대 | [장기 임대](/docs/ko/console/long-term-rentals) 관련 문의입니다. 목록에 없는 구성이나 조건 협의가 필요할 때 이용하세요. |

대기 신청과 한도 증가 요청에는 처리에 필요한 정보를 함께 담습니다 — 필요한 레플리카 수, 볼륨 용량, 예상 사용 기간 등입니다.

<Note>
  요청은 조직 단위로 기록되어 같은 요청이 중복 접수되지 않습니다. 동료가 이미 같은 내용을 요청했다면 중복으로 접수되는 대신 그 요청을 보여 드립니다.
</Note>

## 요청 확인하기

콘솔에서 **요청 내역**을 엽니다. **요청**과 **내 피드백** 두 탭이 있고, 상태·종류·요청자로 걸러 보거나 내 요청만 볼 수 있습니다.

| 상태 | 설명 |
| :-- | :-- |
| **진행 중** | 접수되어 검토 중입니다. |
| **승인됨** | 승인되었습니다. 한도 증가 요청은 이 시점에 새 한도가 이미 적용됩니다. |
| **완료됨** | 처리가 끝나 자원을 쓸 수 있습니다. |
| **거절됨** | 거절되었습니다. 사유는 답변에서 확인할 수 있습니다. |
| **취소됨** | 요청을 직접 철회했습니다. |

진행 중인 요청은 직접 취소할 수 있습니다. 취소하면 그 요청은 종결되지만, 같은 요청을 나중에 다시 보낼 수 있습니다.

## 알림

- **요청 접수 확인** — 요청이 정상적으로 접수됐음을 알립니다.
- **요청 처리 결과** — 어떻게 처리됐는지 담당자 답변과 함께 알립니다.
- **대기 신청 GPU 확보** — 조직 소유자가 아니라 **신청한 본인**에게 콘솔 알림과 이메일로 발송됩니다.
- **레플리카 한도 증가 승인** — 새 한도가 적용되는 시점에 알립니다.

어떤 채널로 받을지는 [알림](/docs/ko/console/notifications)에서 설정할 수 있습니다.
