**계정 설정**은 조직이 아니라 개인에게 속한 설정을 모아 둔 곳입니다. 콘솔 헤더의 프로필에서 열 수 있습니다.

## 프로필 이름

콘솔과 알림 메일에 표시되는 이름(성/이름)입니다.

## 비밀번호

현재 비밀번호를 확인한 뒤 새 비밀번호로 변경합니다.

| 조건 | 값 |
| :-- | :-- |
| 길이 | 8자 이상 |
| 구성 | 영문·숫자·특수문자 중 2종류 이상 |

<Warning>
  비밀번호를 변경하면 보안을 위해 지금 쓰는 기기를 포함한 모든 기기가 곧 로그아웃됩니다. 새 비밀번호로 다시 로그인해 주세요.
</Warning>

GitHub 등 소셜 로그인으로 가입한 계정에는 AirCloud 비밀번호가 없어 여기서 변경할 수 없습니다. 해당 서비스에서 관리해 주세요.

## 이메일 수신 설정

신규 기능, 프로모션, 이벤트 등 마케팅 정보를 이메일로 받을지 선택합니다. 변경하면 즉시 저장됩니다.

알림 메일과는 별개입니다. 어떤 제품 알림을 메일로 받을지는 [알림](/docs/ko/console/notifications) 페이지에서 설정하며, 초대·영수증·인보이스 같은 거래 메일은 항상 발송됩니다.

## 계정 탈퇴

탈퇴하면 계정이 영구적으로 삭제되고, 소속된 조직과 프로젝트에서 관련 데이터가 제거됩니다.

<Warning>
  조직의 **마지막 소유자**라면 탈퇴 시 **조직도 함께 삭제**됩니다. 조직을 유지하려면 다른 멤버에게 소유권을 먼저 이전하세요. [조직 삭제](/docs/ko/console/organization-deletion)를 참고하세요.
</Warning>
