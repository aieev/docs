title: "조직 삭제"

---

조직 소유자는 **조직 → 설정**에서 조직을 영구적으로 삭제할 수 있습니다. 삭제하면 모든 컨테이너가 종료되고 조직의 자원이 정리되며, 모든 멤버가 접근 권한을 잃습니다.

<Warning>
  삭제는 되돌릴 수 없습니다.
</Warning>

## 삭제하기 전에 정리해야 할 것

콘솔이 먼저 조건을 확인합니다. 아래에 해당하는 동안에는 삭제가 막히고, 화면에서 무엇을 해야 하는지 안내합니다.

| 조건 | 해결 방법 |
| :-- | :-- |
| **음수 잔액** | 결제 페이지에서 미납 금액을 정산하세요. |
| **미납 인보이스** | 남은 인보이스를 결제하세요. |
| **진행 중이거나 예정된 장기 임대** | 임대가 끝나기를 기다리거나, 취소 가능한 건은 취소하세요. |
| **후불 결제 조직** | 정산 후 삭제됩니다. 문의를 남겨 주세요. |
| **정지된 조직** | 정지가 해제된 뒤 삭제할 수 있습니다. 문의를 남겨 주세요. |
| **전용 클러스터 사용** | 클러스터 회수 후 삭제됩니다. 문의를 남겨 주세요. |
| **삭제가 중단된 상태** | 이전 삭제가 중간에 멈췄습니다. 같은 화면에서 이어서 진행하세요. |

직접 해결하기 어렵거나 환불·정산이 필요하면 같은 창에서 문의를 남길 수 있습니다. 문의는 [요청 내역](/docs/ko/console/requests) 페이지에 기록되며 답변도 여기서 확인합니다.

## 확인해야 하는 항목

삭제 전에, 조직에 해당하는 항목을 하나씩 확인하게 됩니다.

- **잔여 크레딧은 자동으로 환불되지 않습니다.**
- **회원님이 결제한 건 중** 카드 결제 취소가 가능한 결제가 있으면 건수를 알려 줍니다. 삭제 **전에** [결제 내역](/docs/ko/console/billing#결제-취소와-환불)에서 취소해 주세요. 다른 멤버가 결제한 건은 건수에 포함되지 않으며 그 멤버가 삭제 전에 직접 취소해야 합니다. 삭제 뒤에는 콘솔에서 취소할 수 없습니다.
- 조직의 멤버들이 **즉시 접근 권한을 잃습니다.**
- 조직의 **영구 볼륨 데이터가 복구 불가능하게 삭제됩니다.**
- 대기 중인 초대가 무효화됩니다.
- 실행 중인 컨테이너가 자동으로 종료됩니다.
- 아직 완료되지 않은 결제는, 삭제 이후 완료되더라도 크레딧이 지급되지 않습니다.

<Note>
  잔여 크레딧은 삭제 절차에서 환불되지 않습니다. 지급된 크레딧을 사용하지 않은 카드 결제는 삭제 **전에** 결제 내역에서 직접 취소할 수 있고, 그 밖의 정산이 필요하다면 삭제 **전에** 문의를 남겨 주세요.
</Note>

## 계정 탈퇴

계정 탈퇴는 별도 기능으로 [계정 설정](/docs/ko/console/account)에서 할 수 있습니다. 조직의 **마지막 소유자**라면 탈퇴 시 조직도 함께 삭제되며, 위와 같은 확인 절차를 거칩니다. 조직을 유지하려면 다른 멤버에게 소유권을 먼저 이전하세요.
