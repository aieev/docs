AirCloud 문서의 구조 변경, 신규 가이드 추가, 콘텐츠 개선 사항을 기록하는 페이지입니다.

## 2026-08

### 새 문서

- **장기 임대**: 기간과 할인, 결제, 상태, 취소·환불, 컨테이너에 적용되는 조건을 다루는 콘솔 문서를 추가했습니다. 조직 관리의 오래된 "장비 예약" 섹션을 대체합니다.
- **요청과 대기 신청**: 대기 신청, 레플리카 한도 증가, GPU·템플릿·모델 요청과 요청 내역 확인 방법을 담은 콘솔 문서를 추가했습니다.
- **계정 설정**: 프로필 이름, 비밀번호 변경, 이메일 수신 설정, 계정 탈퇴를 다루는 콘솔 문서를 추가했습니다.
- **조직 삭제**: 삭제 전에 정리해야 할 조건과 복구할 수 없게 제거되는 항목을 정리한 콘솔 문서를 추가했습니다.
- **GPU 가용성과 한도**: 가용성 표시, 영구 볼륨 전용 노드 풀, 레플리카 한도를 설명하는 레퍼런스를 추가했습니다.
- **배포 오류 코드**: 에러 상세 창에 표시되는 모든 코드와 조치 방법을 정리한 레퍼런스를 추가했습니다.

### API 레퍼런스

- **상용 API와 스펙 동기화**: External API 스펙을 상용 서비스가 게시하는 스키마와 대조해 누락된 항목을 채웠습니다 — 목록·상태 응답의 `tags`, 상태 응답의 RFC 9457 `error` 객체, PATCH 요청·응답의 `auth_mode`, 목록 조회의 `project_id` 쿼리 파라미터.
- **엔드포인트 URL 예시**: `serving_endpoint_url` 예시를 더 이상 쓰지 않는 클러스터 번호 경로 대신 통합 형식(`https://ap-1.aieev.cloud/endpoints/<컨테이너-ID>`)으로 바꿨습니다.

### 정정

- **크레딧 단위**: "AU" 표기를 콘솔에서 쓰는 크레딧 단위 **C**로 통일하고, 충전 범위(10,000 C ~ 10,000,000 C)를 명시했습니다.
- **모델 카탈로그**: 제공하지 않는 모델을 지원 목록에서 제거하고 **DeepSeek V4 Flash**와 신규 **Qwen3.8-27B**를 추가했으며, 원화 단가를 상용 카탈로그 기준으로 모두 바로잡았습니다. TTS 요금 단위도 100만 토큰이 아니라 1,000자 기준으로 수정했습니다.
- **컨테이너 상태**: 상태 이름을 콘솔 표기와 맞췄습니다.
- **영구 볼륨**: 용량 범위를 1~1,000GB(기본 30GB)로 정정하고, 실행 중 용량 증설과 여러 경로 마운트를 문서화했습니다.
- **런타임 로그**: 현재의 레플리카 중심 화면에 맞게 다시 썼습니다 — 로그 레벨·소스 필터, 기본 7일 조회, 레플리카별·일괄 다운로드.
- **템플릿**: 옛 카테고리 표를 현재의 작업 종류 / 인터페이스 / 세부 구성 분류로 교체하고, 템플릿 저장 항목을 바로잡았습니다.
- **데스크톱 알림**: 설정 위치가 프로필 설정에서 알림 설정 탭으로 바뀐 것을 반영했습니다.
- **모니터링**: 더 이상 제공하지 않는 작업 에러 수 지표를 삭제했습니다.
- **Air API 문제 해결**: 미확정 상태로 남아 있던 문구를 실제 동작(요청 한도, 모델 접근 권한, 공지 경로)으로 교체했습니다.

### 개선

- **알림**: 모든 알림과 수신자, 콘솔 30일 보관 정책을 담은 이벤트 × 채널 레퍼런스로 다시 썼습니다.
- **컨테이너 배포**: 공유 메모리(`/dev/shm`), 직접 지정할 수 있는 컨테이너 ID와 공개 URL, GPU 가용성이 선택에 미치는 영향을 문서화했습니다.
- **컨테이너 런타임 레퍼런스**: 항목 이름을 콘솔과 맞추고 공유 메모리, 공개 URL 형식, 자동 주입되는 `AIRCLOUD_AUTHORIZED_KEYS` 변수를 추가했습니다.
- **문의 및 피드백**: 제품 관련 요청의 기본 경로로 콘솔 내 요청 창구를 안내합니다.
- **오류 수정**: 개념·과금 문서의 중복된 문장과 표 헤더를 고치고, FAQ·API 레퍼런스 개요·릴리즈 노트의 깨진 내부 링크를 바로잡았습니다.

## 2026-06

### Air Container

- **컨테이너 태그**: 사용자 정의 이름으로 여러 컨테이너를 묶어 그룹화하고 필터링하는 기능 안내 추가
- **'시작·정지·재시작' → '컨테이너 관리'로 통합**: 태그 기능 포함, 생명주기·과금 규칙 내용 재편
- **영구 볼륨 개선**: 오토스케일링 배포 지원, 생성 시 새/기존 볼륨 선택, 여러 배포 간 공유, 중지 상태에서 볼륨 활성화·교체 기능 안내 추가
- **레플리카 쿼터 제한**: 쿼터 초과 시 관리자 문의, GPU 수요 부족 시 대기 신청(waitlist) 안내 추가
- **SSH 키 컨테이너별 적용**: 특정 컨테이너에만 적용하거나 삭제 없이 활성화/비활성화하는 기능 안내 추가
- **웹 터미널 레플리카 선택**: 다중 레플리카 환경에서 접속 대상 선택, 레플리카 교체 시 자동 재연결 안내 추가

### Air API

- **모니터링 페이지 신규 추가**: 프로젝트 모니터링(Air API 탭) 지표 안내, 조직 사용량 관리에서 Air API 집계 확인 방법 추가
- **사용량 개선 반영**: 지출 집계 정확도 개선, 필터 일관성 정리, 차트·기록에 모델 표시 이름 추가 내용 반영
- **코드 예시 Shell 탭 추가**: Chat·TTS·Embedding 세 섹션 모두 Python / Node.js / cURL / Shell 4종으로 통일

### 레퍼런스

- **인프라 및 리소스 타입 페이지 신규 추가**: AirCloud Plus·Zero 비교 카드, GPU 스펙 테이블(VRAM·RAM·vCPU), 모델 크기별 VRAM 권장 가이드, 가격 안내 페이지 링크

### 콘솔

- **과금 — 환불 정책 섹션 추가**: 7일 이내 미사용 크레딧 환불 기준, 부가세 제외 공급가액 기준, 청구 이의 제기 안내, 이용약관 링크

### 지원

- **FAQ AccordionGroup 개편**: 기존 헤딩 나열 방식을 접기/펼치기 형태로 변경해 가독성 개선

### 시작하기

- **AirCloud란? 페이지 개편**: 배포 방식 선택(Air API·Air Container)과 인프라 옵션 선택(Zero·Plus) 카드 구조로 재편, 중복 섹션 제거
