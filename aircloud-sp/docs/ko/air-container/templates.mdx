템플릿은 자주 사용하는 AI/ML 환경을 사전 구성해 놓은 컨테이너 설정입니다. Docker 이미지, 포트, 환경 변수 등을 매번 직접 입력하지 않고 템플릿을 선택하는 것만으로 원하는 환경을 바로 배포할 수 있습니다.

## 공식 템플릿

AirCloud에서 제공하는 공식 템플릿은 컨테이너 생성 화면의 **템플릿 선택**에서 확인할 수 있습니다. 무엇을 하려는지를 기준으로 묶여 있고, 이름으로 검색할 수도 있습니다.

| 분류 | 값 |
| --- | --- |
| **주요 작업** | PyTorch, TensorFlow, 기타 딥러닝, vLLM, Hugging Face TGI, Ollama, ComfyUI, Stable Diffusion WebUI, 기타 서빙, 범용 작업 환경, 기타 개발 환경 |
| **인터페이스** | Jupyter, VS Code, 또는 없음(서빙 API) |
| **세부 구성** | 같은 작업·인터페이스 안에서 달라지는 부분 — 예: CUDA 버전, Python 버전, 함께 들어 있는 도구 |

이미지가 `sshd`를 실행하는 템플릿에는 **SSH 접속** 지원 표시가 붙습니다. 컨테이너에 SSH 키를 등록하면 Jupyter나 VS Code와 함께 사용할 수 있습니다.

<Note>
  제공 템플릿 목록은 업데이트될 수 있습니다. 최신 목록은 컨테이너 생성 화면에서 직접 확인하세요.
</Note>

## 내 템플릿

기존 컨테이너 설정을 템플릿으로 저장해 두면, 이후 배포 시 동일한 환경을 빠르게 재사용할 수 있습니다.

### 템플릿 저장 방법

1. Air Container 목록에서 저장할 컨테이너 카드 우측 상단의 **⋮** 아이콘 클릭

![Custom Template](/images/custom-template.png)

2. **템플릿 저장** 선택
3. 템플릿 정보 입력 후 **저장**

![Custom Template Modal](/images/custom-template-modal.png)

| 항목 | 설명 |
| --- | --- |
| 템플릿 이름 | 템플릿을 구분할 이름 (필수) |
| 설명 | 템플릿에 대한 간단한 설명. 선택 화면의 템플릿 카드에 표시됩니다 (선택) |
| 아이콘 | 템플릿 카드에 표시할 아이콘 |

저장이 완료되면 이후 컨테이너 생성 시 **내 템플릿만** 필터에서 저장한 템플릿을 선택할 수 있습니다.

<Note>
  내 템플릿은 해당 프로젝트의 접근 권한이 있는 모든 멤버에게 공유됩니다. 삭제는 템플릿을 만든 사람이나 프로젝트 관리자만 할 수 있고, 기본 제공 템플릿은 삭제할 수 없습니다.
</Note>

## 템플릿 선택 방법

컨테이너 배포 시 이미지 설정 단계에서 템플릿을 선택합니다.

1. 컨테이너 생성 화면에서 **템플릿 선택** 클릭
2. 프레임워크 태그로 필터링하거나 이름으로 검색
3. 원하는 템플릿 선택 후 **저장**
4. 이후 단계에서 포트, 환경 변수, 리소스 등 추가 설정 진행

<Tip>
  처음 배포하는 경우 공식 템플릿으로 시작해 환경을 확인한 뒤, 필요에 따라 커스텀 이미지로 전환하는 방법을 권장합니다.
</Tip>
