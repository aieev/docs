컨테이너를 재시작하거나 중지해도 데이터가 유지되는 영구 저장소입니다. 하나의 프로젝트 안에서 볼륨을 공유하여 여러 컨테이너 또는 여러 레플리카가 함께 사용할 수 있습니다.

## 영구 볼륨으로 할 수 있는 것

영구 볼륨을 배포 전반에서 더 유연하게 사용할 수 있습니다.

- **오토스케일링 지원**: 오토스케일링과 여러 레플리카를 사용하는 배포에도 볼륨을 연결할 수 있습니다.
- **생성 시 새/기존 볼륨 선택**: 배포를 생성할 때 새 볼륨을 만들거나 기존 볼륨을 재사용할 수 있습니다.
- **여러 배포에서 공유**: 하나의 볼륨을 여러 배포에 연결할 수 있으며, 볼륨 선택 시 이미 사용 중인 배포를 함께 보여줍니다.
- **중지 상태에서 변경**: 배포가 중지(**대기중**)된 동안 연결된 볼륨을 활성화/비활성화하거나 교체할 수 있습니다.
- **실행 중 용량 증설**: 이미 사용 중인 볼륨의 용량을 컨테이너를 멈추지 않고 늘릴 수 있습니다.
- **여러 경로에 마운트**: 하나의 볼륨을 컨테이너 안의 여러 경로에 동시에 마운트할 수 있습니다.

## 사용 방법

### 새 볼륨 만들기

컨테이너 생성 시 영구 볼륨을 새로 생성하여 연결할 수 있습니다. 볼륨 용량은 **1GB ~ 1,000GB** 범위에서 지정하며 기본값은 **30GB**입니다.

실제 상한은 컨테이너가 배치되는 장비의 남은 용량에도 영향을 받습니다. 요청한 용량이 이를 넘으면 `VOLUME_SIZE_EXCEEDED` 오류로 생성이 실패하므로, 용량을 줄여 다시 시도하세요.

![Shared Storage1](/images/shared-storage1.png)

### 기존 볼륨 연결하기

다른 컨테이너에 이미 사용 중인 볼륨을 다시 연결하여 같은 볼륨을 공유할 수 있습니다. 볼륨 선택 시 해당 볼륨을 현재 사용 중인 배포 목록도 함께 표시됩니다.

![Shared Storage2](/images/shared-storage2.png)

<Tip>
  **하나의 컨테이너에서 여러 레플리카가 같은 볼륨을 함께 사용할 수 있습니다.** 오토스케일링이 활성화된 배포에서도 동일하게 동작합니다.
</Tip>

### 여러 경로에 마운트하기

**마운트 경로**에는 쉼표로 구분해 여러 경로를 넣을 수 있습니다. 예를 들어 `/workspace, /data`처럼 입력하면 같은 볼륨이 컨테이너 안의 두 경로에 모두 마운트됩니다.

### 볼륨 용량 늘리기

이미 연결된 볼륨의 용량은 **컨테이너가 실행 중인 상태에서도** 늘릴 수 있습니다. 변경은 1분 이내에 반영됩니다.

<Note>
  용량은 늘릴 수만 있고 줄일 수는 없습니다.
</Note>

### 중지 상태에서 볼륨 변경하기

볼륨을 활성화/비활성화하거나 교체하려면 컨테이너가 **대기중(중지)** 상태여야 합니다.

- 연결된 볼륨을 **비활성화**하거나 다시 **활성화**할 수 있습니다.
- 연결된 볼륨을 다른 볼륨으로 **교체**할 수 있습니다.

변경 사항은 컨테이너를 다시 시작할 때 적용됩니다.
