지금 컨테이너를 시작할 수 있는지는 두 가지가 따로 결정합니다. **GPU에 여유 자원이 있는지**, 그리고 **조직의 레플리카 한도**에 여유가 있는지입니다. 이 페이지는 둘을 나눠 설명하고, 각각에 막혔을 때 무엇을 하면 되는지 안내합니다.

## GPU 가용성

컨테이너 생성 화면의 GPU 목록에는 실제 장비 현황에서 가져온 가용성 표시가 붙습니다. **가용성 새로고침**으로 화면을 새로 고치지 않고 다시 확인할 수 있습니다.

| 표시 | 의미 |
| :-- | :-- |
| **여유** | 여유 자원이 충분합니다. |
| **보통** | 여유 자원이 어느 정도 있습니다. |
| **부족** | 여유 자원이 얼마 남지 않았습니다. 설정하는 사이에 소진될 수 있습니다. |
| **가용 자원 없음** | 품절입니다. 자원이 확보될 때까지 선택할 수 없습니다. |

표시가 없다면 그 시점에 가용성을 확인하지 못한 것입니다. 컨테이너를 만들 수는 있지만 시작이 지연될 수 있습니다.

<Note>
  가용성은 AirCloud가 보유한 전체 장비 수가 아니라, 해당 컨테이너가 **실제로 배포될 풀**을 기준으로 합니다. 장기 임대로 확보된 자원이나 다른 배포 형태로 예약된 자원은 여유로 잡히지 않습니다.
</Note>

### 영구 볼륨은 별도 풀을 씁니다

영구 볼륨을 쓰는 컨테이너는 전용 노드 풀에서 실행됩니다. 이 풀의 여유는 따로 계산되므로, 같은 GPU라도 볼륨을 끈 컨테이너에는 여유가 있고 볼륨을 켠 컨테이너에는 품절일 수 있습니다.

여기서 두 가지가 따라옵니다.

- 영구 볼륨을 켜고 끄면 선택 가능한 GPU가 달라질 수 있습니다.
- 영구 볼륨과 CPU 타입은 함께 선택할 수 없습니다. 전용 풀은 CPU 타입을 구분하지 않고 배정하기 때문입니다.

### GPU가 품절일 때

- **대기 신청** — 자원이 확보되면 콘솔 알림과 이메일로 알려 드립니다.
- **다른 GPU 선택** — 가용성은 모델마다 다릅니다.
- **장기 임대** — [장기 임대](/docs/ko/console/long-term-rentals)로 미리 자원을 확보할 수 있습니다. 지금 여유가 없는 기간도 협의할 수 있습니다.

## 레플리카 한도

가용성과 별개로, 조직에는 GPU 타입별로 실행할 수 있는 레플리카 수 한도가 있습니다. 생성 화면에는 한도 중 얼마를 이미 쓰고 있는지와, 지금 바로 시작할 수 있는 수가 함께 표시됩니다.

| 상황 | 화면 안내 |
| :-- | :-- |
| 한도에 여유가 있음 | 지금 바로 시작할 수 있는 레플리카 수를 보여줍니다. |
| 한도를 모두 사용 중 | 컨테이너는 만들 수 있지만, 시작하려면 다른 컨테이너를 멈추거나 레플리카 수를 줄여야 합니다. |
| 한도가 1 | 오토스케일링에는 최소 2가 필요하므로 자동으로 꺼집니다. |

한도를 늘리려면 레플리카 설정이나 한도 화면에서 증가를 요청하세요. 승인되면 새 한도가 자동으로 적용되고 알림을 받습니다. [요청과 대기 신청](/docs/ko/console/requests)을 참고하세요.
