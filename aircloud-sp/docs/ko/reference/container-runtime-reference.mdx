Air Container 배포 시 자주 사용하는 런타임 설정 항목을 정리한 문서입니다.

## 지원 레지스트리

- GCP Artifact Registry
- AWS ECR
- GitHub Container Registry
- Docker Hub

<Note>
  비공개 레지스트리를 사용하는 경우에는 인증 정보가 필요합니다.
</Note>

## 자주 사용하는 설정 항목

### 시작 명령

컨테이너 실행 시 사용할 시작 명령입니다.

### 포트

서비스가 외부 요청을 받을 포트입니다.

### 헬스 체크 URL

컨테이너가 정상 동작 중인지 확인하기 위한 경로입니다.

### 메트릭 경로

애플리케이션이 메트릭을 노출하는 경로입니다. 예: `/metrics`

### 헬스 체크 최대 대기 시간

헬스 체크 응답을 기다리는 최대 시간입니다. 기본값 **300초**.

### 부팅 대기 시간

컨테이너 시작 프로세스가 끝날 때까지 기다리는 최대 시간입니다. 기본값 **600초**.

### 환경 변수

애플리케이션 실행에 필요한 환경 변수입니다.

배포 시점에 AirCloud가 `AIRCLOUD_AUTHORIZED_KEYS` 변수를 함께 주입합니다. 해당 컨테이너에 등록된 SSH 공개 키가 담깁니다. [SSH로 접속하기](/docs/ko/air-container/connect-with-ssh)를 참고하세요.

### 공유 메모리 (`/dev/shm`)

PyTorch DataLoader처럼 공유 메모리를 쓰는 워크로드를 위한 `/dev/shm` 크기입니다. 기본은 꺼짐이며 이때 인스턴스 메모리의 절반이 적용됩니다. 지정하면 1GB부터 인스턴스 메모리 크기까지 설정할 수 있습니다.

### 컨테이너 ID

컨테이너 식별자입니다. 자동 생성되지만 고정 슬러그(소문자·숫자·하이픈)로 직접 지정할 수 있고, 공개 URL에 그대로 들어갑니다.

### 공개 URL

배포된 컨테이너는 `https://ap-1.aieev.cloud/endpoints/<컨테이너-ID>` 주소로 서비스됩니다. 생성 화면에서 컨테이너 ID를 바꾸면 URL 미리보기가 함께 갱신됩니다.

## 운영 권장 사항

- 공개 레지스트리와 비공개 레지스트리 설정을 구분해 관리
- 포트와 헬스 체크 경로를 배포 전 미리 검증
- 운영 환경 변수는 배포 전 다시 확인
- 설정 변경 후에는 로그와 Usage 상태를 함께 점검
